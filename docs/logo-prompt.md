# Logo source

The logo was generated with the built-in `image_gen` tool. The source PNG is `macos/assets/code-push-tags-logo.png`. It has transparency and measures 1254 × 1254 pixels. The app uses this source for its header and generated Finder/Dock icon.

Prompt, verbatim:

```text
Use case: logo-brand. Create one finished silly but polished mascot logo / macOS app icon for a small app called Code Push Tags, a personal opt-in soundboard for Git pushes, merges and CI failures. Primary subject: an overconfident anthropomorphic cassette tape wearing enormous DJ headphones, with the cassette reels as expressive half-lidded eyes and a cheeky grin. It should look like a ridiculous little mixtape DJ who takes shipping code far too seriously. Strong simple silhouette, chunky clean shapes, sticker-like contemporary cartoon illustration with a little tactile plastic, readable at Dock-icon size. Palette from the actual app: nearly black charcoal, bright mint green, soft electric violet, with a tiny coral accent. One character only, centered, square composition with generous clean margins; no words, letters, watermark, guns, real people, or existing brand logos. Transparent background with actual alpha, preserving transparency around the mascot; no white rectangle. This should feel fun and intentionally dumb, with professional visual clarity, suitable both as a transparent README logo and an app icon. This is the final usable asset, not a sheet of options, not an app screenshot.
```

Decided by: person (Max). Add a silly logo for the app.

Decided by: agent. Use a cassette DJ in the existing mint and purple palette.
