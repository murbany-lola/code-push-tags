# Social posting kit

[Download the complete ZIP](https://github.com/murbany-lola/code-push-tags/releases/download/v0.4.2/Code-Push-Tags-Social-Kit.zip). It contains the video, cover, captions, comments, replies, and posting steps.

1. Upload `01-Upload.mp4`.
2. Select `02-Cover.png` as the cover.
3. Copy a caption from `03-Captions.txt`.
4. Add the first comment from `04-Comments-and-replies.txt`.

Use `05-Story-and-group-chat.txt` for other sharing text. Read `06-Sounds-and-options.txt` for bundled clips and library updates.

The [video](../instagram-reel.mp4) is 25 seconds at 1080 × 1920 and 30 fps. It shows the current event columns, producer groups, and compact LED player. Each audio preview shows its matching clip name and app card. The footage contains only the app. No private repository names appear.

The app includes 17 clips, including nine generated coding parodies. Shared-library updates can add clips without a new app download. Local WAV import through the app is not implemented. A fork can supply its own catalog.

The kit contains drafts only. No social account was used to publish them.
