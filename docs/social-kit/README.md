# Social posting kit

[Download the complete ZIP](https://github.com/murbany-lola/code-push-tags/releases/download/v0.3.1/Code-Push-Tags-Social-Kit.zip). It contains the video, cover, captions, comments, replies, and posting steps.

1. Upload `01-Upload.mp4`.
2. Select `02-Cover.png` as the cover.
3. Copy a caption from `03-Captions.txt`.
4. Add the first comment from `04-Comments-and-replies.txt`.

Use `05-Story-and-group-chat.txt` for other sharing text.

The [video](../instagram-reel.mp4) is 24 seconds at 1080 × 1920 and 30 fps. Each sound preview shows its matching card, name, and waveform. The footage shows no private repository names.

The kit contains drafts only. No social account was used to publish them.
