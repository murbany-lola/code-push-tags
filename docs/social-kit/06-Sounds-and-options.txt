The bundle also includes eight meme and system-sound clips. Each person selects sounds for their own Mac. Installation does not enroll coworkers.

GET MORE SHARED SOUNDS

Select Refresh Library in the app. The app also checks for shared-library updates once per hour. New shared clips do not require a new DMG. The app keeps a complete local copy for offline use.

BRING YOUR OWN WAV FILES

A local file-import button and separate optional pack selector are not implemented. To add your own clips now, fork the source, add PCM WAV files and manifest entries, and use your fork as the library source. Follow FORKING.md.

Code and audio have separate license scopes. The original platform code uses MIT. Audio is outside that code license. Some WAV files were converted from MP3 sources. Conversion does not improve source quality.
